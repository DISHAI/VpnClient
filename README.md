# 🛡 VPN Client

Современный VPN-клиент для Windows с поддержкой VLESS и Hysteria2.

![Windows](https://img.shields.io/badge/Windows-10%2F11-blue?logo=windows)
![License](https://img.shields.io/badge/License-MIT-green)
![Status](https://img.shields.io/badge/Status-Active-success)

## 🚀 Протоколы

- **VLESS** — TCP, WebSocket, gRPC, HTTP/2, TLS, Reality
- **Hysteria2** — QUIC, obfuscation

## 📋 Возможности

- Импорт серверов из URI-ссылок (`vless://`, `hysteria2://`, `hy2://`)
- Подписки — автоматическая загрузка и обновление списков серверов
- Сворачиваемые группы серверов по подпискам
- Поиск и фильтрация по протоколам
- Пинг всех серверов в один клик (TCP-замер)
- Карточки серверов с бейджами, задержкой и статусом

## 🔧 Режимы работы

| Режим   | Описание                                              |
|---------|-------------------------------------------------------|
| **Proxy** | SOCKS5 + HTTP прокси на локальном порту              |
| **TUN**   | Полный VPN-туннель всего системного трафика (через sing-box) |

## 🎨 Интерфейс

- Тёмная тема в стиле GitHub
- Сворачивание в трей при закрытии
- Таймер подключения
- Логи в реальном времени
- Диагностика подключения (TCP-пинг, проверка бинарников, тестовый запуск)

## ⚙️ Технические детали

- Платформа: **Windows 10/11**
- Автоматическая настройка системного прокси
- Запрос прав администратора (для режима TUN)
- Сборка в один `.exe` без консоли
- Ядра: **Hysteria2 native** + **Xray-core** + **Sing-box**

## 📦 Установка

Установка не требуется — всё в одном файле.

1. Скачайте последний релиз из раздела [Releases](../../releases)
2. Запустите `VPNClient.exe`
3. Для режима TUN запустите от имени администратора

## 🖥 Использование

1. Добавьте сервер через URI или подписку
2. Выберите нужный сервер
3. Нажмите **Подключить**
4. Выберите режим (Proxy или TUN)
